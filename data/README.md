# Dataset

`diabetes.csv` is the **Pima Indians Diabetes Database** (National Institute of Diabetes and Digestive and
Kidney Diseases, distributed via the UCI Machine Learning Repository). It contains 768 records of women aged
21 and over of Pima Indian heritage, with 8 medical predictor variables and a binary outcome.

Columns: Pregnancies, Glucose, BloodPressure, SkinThickness, Insulin, BMI, DiabetesPedigreeFunction, Age, Outcome.

Zero values in Glucose, BloodPressure, SkinThickness, Insulin and BMI are physiologically impossible and are
treated as missing ("not recorded") inside the modelling pipeline.

This file is included unchanged for education. It is not a clinical dataset for decisions about any individual.
